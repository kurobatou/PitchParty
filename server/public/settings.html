    Certificado HTTPS con dominio propio (opcional)

    Por defecto se usa un certificado autofirmado (pide aceptar una advertencia una vez por dispositivo). Si tenés un dominio propio administrado en Cloudflare, podés conseguir acá un certificado real de Let's Encrypt — se valida por DNS, así que no hace falta exponer este servidor a internet para conseguirlo. Necesitás un subdominio (ej: karaoke.tudominio.com) y un token de API de Cloudflare con permiso Zone:DNS:Edit sobre esa zona.
